# Persona Library

Persona JSON files live here.

Persona files should describe only:

- Personality traits
- Behavior hints
- Speaking style
- Thinking style
- Memory preference

Persona files must not describe:

- Agent goals
- Scene goals
- Identity information
- Willingness scoring logic
- Real-time turn order logic

The persona dealer can work with any validated persona array, so tests do not depend on this folder being complete.
