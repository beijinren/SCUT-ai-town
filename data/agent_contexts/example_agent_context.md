# Agent Context Example

## Architecture
This document is owned by one agent. Scene sections can be replaced when the
scene changes.

## Scene
Use the current workshop scene, phase, public goal, and spatial context.

## Persona
Stable personality/style information goes here.

## Identity
Stable role identity and private goal go here.

## PrivateThoughts
Only this agent's private thoughts go here. Do not merge thoughts from other
agents.

## KnownFacts
Facts this agent legally knows through public scene setup or InformationGraph
paths go here.

## SpatialContext
Current area, nearby objects, and available affordances go here.

## TurnPolicy
Only one participant speaks per visible turn. Every agent may think privately.
